# NeoLoader

Десктопное приложение для скачивания видео/аудио с YouTube (Python + PyQt6 + yt-dlp),
интерфейс — React внутри `QWebEngineView`. Подробное устройство — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Установка

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

Фронтенд собирается отдельно (без этого окно откроет пустую страницу):

```bash
npm --prefix frontend install
npm --prefix frontend run build
```

Для склейки видео+аудио (а значит и для качества выше 360p, и для выбора русской
аудиодорожки), для извлечения аудио и для ВСЕЙ вкладки «Конвертер» нужен **ffmpeg**
в PATH — yt-dlp его не устанавливает. Скачать: https://ffmpeg.org/download.html
Приложение показывает наличие ffmpeg в «Настройки → Статус системы» и явно пишет
в лог, если склейка недоступна.

Набор доступных кодеков зависит от сборки ffmpeg: минимальные сборки идут без
libx265/libsvtav1, и приложение это учитывает — в списках показываются только
энкодеры, которые реально есть в системе.

## Запуск

```bash
python main.py
```

Флаг `--debug` включает подробный лог. Окно закрывается в трей; полный выход —
пункт «Выход» в меню трея.

## Возможности

### Загрузка

- Ссылка на видео, плейлист, **канал**, `youtu.be`, Shorts, ссылки с таймкодами —
  тип определяется автоматически.
- **Плейлисты и каналы**: список разворачивается в таблицу с названиями и
  длительностями, можно отфильтровать по названию и отметить только нужные ролики.
  Каждое видео становится ОТДЕЛЬНОЙ задачей, поэтому пауза, отмена и повтор работают
  поштучно, а недоступный ролик не роняет весь пакет.
- Предпросмотр: название, канал, длительность, миниатюра, список доступных аудиоязыков.
- Качество 4K…360p, выбор видео/аудио кодека и контейнера (mp4/mkv/webm/mov).
- **Только аудио** — кнопка «MP3 320» в один клик либо ручной выбор формата
  (mp3, m4a, opus, vorbis, flac, wav, aac, alac) и битрейта (96–320 kbps).
  Отдельный режим **«original»**: аудиопоток сохраняется ровно таким, каким его
  отдаёт YouTube — без перекодирования и без второй потери качества.
- **Русская аудиодорожка** (авто-дубляж YouTube). Если её нет — приложение говорит
  об этом явным сообщением, а не тихо скачивает оригинал.
- **Краткое саммери по видео** по субтитрам. Без ключа API работает встроенный
  офлайн-алгоритм; с ключом Anthropic (Настройки → Саммери по видео) пересказ делает Claude.

### Очередь

- Пауза, продолжение и отмена — и для качающейся задачи, и для ещё ожидающей.
- «Пауза для всех» / «Продолжить все» / «Убрать ожидающие».
- Перестановка ожидающих задач стрелками вверх/вниз.
- Прогресс и скорость по каждой задаче; параллельные загрузки (1–5).
- Состояние очереди переживает перезагрузку окна: интерфейс досинхронизируется
  с бэкендом, а не показывает пустой список при работающей загрузке.

### Конвертер (вкладка «Конвертер»)

Локальные операции над уже существующими файлами — без интернета, через ffmpeg.
Ключевой принцип: **что можно сделать без перекодирования, делается без него**
(мгновенно и без потери качества); каждая операция честно помечена как «без потерь»
или «перекодирование».

- **Смена контейнера** (MKV ↔ MP4 ↔ MOV ↔ WebM ↔ AVI ↔ TS ↔ FLV) — переписывается
  только оболочка файла. Перекодируется ровно тот поток, который новый контейнер
  физически не умеет хранить, остальные копируются.
- **Обрезка по времени** — без перекодирования (мгновенно, начало сдвигается к
  ближайшему ключевому кадру) либо точно до секунды с перекодированием.
- **Замена звуковой дорожки** дорожкой из другого файла — видеопоток не трогается
  вообще. Можно оставить и оригинальную дорожку и проставить язык новой.
- **Извлечение аудио** в mp3/m4a/opus/ogg/flac/wav/ac3/aac или «как есть»
  (копия дорожки байт в байт, если её кодек подходит контейнеру).
- **Конвертация** с явным выбором кодеков: H.264, H.265/HEVC, VP9, VP8, AV1, ProRes,
  MPEG-4, MJPEG для видео; AAC, MP3, Opus, Vorbis, FLAC, PCM, AC-3, E-AC-3, ALAC для
  звука. Плюс масштабирование и ползунок качества.
- **GIF** из фрагмента (со своей палитрой — иначе GIF выглядит грязно) и **кадр**
  в PNG/JPEG/WebP/BMP/TIFF.
- **Пакетный режим**: выбрал двадцать файлов, задал формат — получил двадцать задач.
- Список кодеков строится по РЕАЛЬНЫМ возможностям установленного ffmpeg
  (`/api/media/capabilities`), а не по захардкоженному списку.

### Остальное

- Субтитры (.srt), прокси, куки из браузера, шаблон имени файла.
- Кодеки по умолчанию, качество по умолчанию, формат и битрейт аудио — в настройках.
- Тёмная/светлая тема, RU/EN интерфейс, история последних 50 загрузок с кнопкой
  «показать в папке».

## Сборка в exe

```bash
npm --prefix frontend run build
pyinstaller build.spec
```

Результат — папка `dist/NeoLoader/` с `NeoLoader.exe` внутри (onedir, не onefile:
onefile распаковывался во временную папку при каждом запуске, и антивирус
пересканировал ~200 МБ на каждом старте).

**Как проверять сборку.** Только двойным кликом или `Start-Process` — БЕЗ
перенаправления вывода. `NeoLoader.exe > log.txt` создаёт валидный stdout и
маскирует целый класс ошибок windowed-режима (в этом проекте так был пропущен
падавший поток API). Что происходит внутри — видно в
`%APPDATA%\NeoLoader\logs\app.log`: туда пишется и старт API, и вывод
`console.*` из самой страницы, включая строку
`[neoloader] backend online|unreachable`.

ffmpeg в сборку по умолчанию не входит — либо он есть в PATH на целевой машине,
либо положите `ffmpeg.exe`/`ffprobe.exe` в `assets/bin/` перед сборкой, и
`build.spec` подхватит их автоматически.

## Структура проекта

```
yt_downloader/
├── main.py                    точка входа: QApplication, single-instance, трей, uvicorn-поток
├── build.spec                 PyInstaller (onedir)
├── core/
│   ├── settings_manager.py    JSON-конфиг и история
│   ├── video_info.py          анализ ссылки без скачивания
│   ├── resolver.py            snapshot форматов + построение планов загрузки
│   ├── download_manager.py    очередь, потоки, yt-dlp, ffmpeg-постпроцессинг
│   ├── summarizer.py          субтитры -> саммери (Claude или локальный алгоритм)
│   ├── media_tools.py         ffmpeg: ремукс/обрезка/замена дорожки/конвертация
│   ├── media_jobs.py          очередь локальных ffmpeg-задач
│   ├── ffmpeg_locator.py      поиск ffmpeg/ffprobe
│   ├── std_streams.py         починка None-потоков в windowed-сборке
│   └── js_runtime.py          доступные JS-движки для челленджей YouTube
├── api/server.py              FastAPI + WebSocket + раздача фронтенда на 127.0.0.1:8756
├── ui/
│   ├── web_window.py          окно-хост с QWebEngineView
│   ├── dialogs.py             нативные диалоги из фонового потока
│   ├── tray.py                иконка и меню в трее
│   └── single_instance.py     защита от второго запуска
└── frontend/                  React + TypeScript + Tailwind
```
